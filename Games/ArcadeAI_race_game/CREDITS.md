# Créditos

- **Asfalto Vivo** — jogo, código, pistas, cena 3D, interfaces e áudio sintetizado
  (Web Audio) desenvolvidos para este projeto. Não há assets externos: geometria,
  decoração e sons são gerados em tempo de execução.
- **Three.js** (MIT) — motor 3D, usado de `node_modules/three` servido em `/vendor/`.
  https://threejs.org
- **ws** (MIT) — servidor WebSocket em Node.

Nenhuma outra biblioteca, fonte, imagem, modelo ou som de terceiros é usada.
